How to Use Saleo Builder

      

        
1
Select a Brand Kit
Choose an existing Brand Kit to auto-populate brand details, or create one in Brand Kit Builder first.

        
2
Add a Synopsis
Type a synopsis, select a script from Script Writer, or upload a PDF/DOCX demo script.

        
3
Generate Token Values
AI generates values for all Saleo template tokens based on your brand. Review and edit them.

        
4
Create Your Saleo View
One click creates a personalized Saleo view and shares it with you with edit access.

        
5
Download Images
Download the brand logo and persona headshot, then upload them into Saleo's image tokens.

        
6
Demo!
Open your view in the Saleo Chrome extension and demo with fully personalized data.
